# Redesign & Page Modification Guidelines

When requested to redesign or make design changes to any page:

1. **Check Live Website**:
   - Always inspect the live website (`https://sssutms.co.in/`) for reference.
   - Verify if any content, data, or images are present on the live site that are missing locally, and update the local site accordingly.

2. **Handle Missing Images**:
   - If an image is missing on both local and live websites, generate/create relevant images.
   - For missing individual profile/person images, use a standard dummy user image placeholder.

3. **Preserve Current Data & Content**:
   - Do **NOT** modify or delete existing text, data, or content of the current website unless explicitly requested.

4. **Local Assets Only (No Hotlinking)**:
   - Always download images, PDFs, or other media from the live website locally into the project folders (e.g., `assets/` or page subdirectories) before using them.
   - Do **NOT** use direct live links (`https://sssutms.co.in/...`) for images or document files.
